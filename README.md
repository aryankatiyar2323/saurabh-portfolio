# Saurabh Katiyar - Premium Electrical Contractor Portfolio

A state-of-the-art, highly interactive portfolio website built for **Saurabh Katiyar**, a leading force in large-scale electrical contracting with over 15+ years of experience. This website is designed to reflect the precision, scale, and high-stakes nature of industrial and commercial electrical infrastructure.

## ⚡ Features

- **Immersive 3D Preloader**: A custom-built, hardware-accelerated 3D rotating cube and holographic text sequence that seamlessly morphs into the landing page using layout animations.
- **Premium Animations**: Powered by Framer Motion, featuring bespoke text-wave interactions, hover-responsive elements, and dynamic stagger reveals.
- **Smooth Parallax Scrolling**: Integrated with Lenis for buttery-smooth scrolling, coupled with parallax effects on project imagery that shift based on the user's scroll depth.
- **Circuit Board Aesthetics**: Custom-designed, glowing SVG circuit board patterns that slowly pulse in the background to heavily lean into the electrical engineering theme.
- **Immersive Contact Modal**: A glassmorphic, full-screen contact interface featuring real-time input highlighting, a seamlessly styled `react-select` dropdown, and simulated "transmitting" animations.
- **Mobile-First Responsiveness**: Hand-tailored to look flawless on mobile devices. Animations gracefully degrade or adapt to touch interfaces (e.g., hiding the custom cursor, scroll-linked animations, pulsing buttons, and a quick-access floating WhatsApp dialer).

## 🛠️ Tech Stack

- **Framework**: React.js (Vite)
- **Styling**: Vanilla CSS with CSS Variables and Glassmorphism techniques
- **Animations**: Framer Motion
- **Smooth Scrolling**: Lenis
- **Icons**: Lucide React
- **Forms**: React-Select (Custom Themed)

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/aryankatiyar2323/saurabh-portfolio.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
